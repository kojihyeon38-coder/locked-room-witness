# 잠긴 방의 증인 — 협동 추리 방탈출

설치 없이 PC·모바일 브라우저에서 즐기는 1~6인 협동 방탈출.
접속 주소를 열고 "친구 초대" 링크를 공유하면 함께 할 수 있습니다.

- 테마 3종, 퍼즐 9종, 매 게임 정답 변경
- 방장의 브라우저가 서버 역할을 합니다. 방장이 창을 닫으면 게임이 멈춥니다.
- 접속 중계에 PeerJS 공개 서버를 사용하며, 일부 회사망·통신망에서는 연결되지 않을 수 있습니다.
- 정답이 브라우저에서 계산되므로 개발자 도구로 확인할 수 있습니다. 친구끼리 즐기는 용도입니다.
